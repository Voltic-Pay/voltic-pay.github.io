A wallet built for people

Self-custodial by default. Voltic never holds your keys or routes your payment through a company.

Voltic is an Android wallet built on Arbitrum. Hold your phone near a merchant's and the payment settles over NFC, or scan a QR code if that's easier. Either way, the transfer happens directly between two wallets: you sign it, the network confirms it, and that's the whole flow.

Why it exists

Most crypto wallets are built for trading. Voltic is built for paying.

True P2P privacy

Payments go directly between the two of you. No company sits in the middle logging your spending.

Zero middleman fees

No 2% cut for a payment processor. What you send is what they get.

KYC-free

No ID checks, no onboarding forms. Install it and you're already set up.

One network, done well

No picking through a hundred coins on ten chains. Voltic sticks to Arbitrum so the experience stays simple.

Full self-custody

Only your seed phrase controls the wallet. Nobody else can freeze or touch it.

Works with what you have

Already have a self-custodial wallet? Import the same seed phrase and your balance comes with it.

Install it, or build it yourself

Install the app

01

Download the APK from the GitHub releases page and install it — Android will warn you it's from outside the Play Store, that's expected for an early build.

02

Create a wallet in the app, or restore one with an existing seed phrase.

03

Fund it with ETH on Arbitrum — bridge or swap into the account address shown on your dashboard.

04

Tap or scan to pay. That's the whole app.

Build it yourself

# clone and build from source
git clone https://github.com/voltic-pay/voltic.git
cd voltic
# add your Arbiscan key for tx history (optional)
echo "ARBISCAN_API_KEY=your_key" >> local.properties
./gradlew assembleDebug

Needs Android Studio Ladybug+, JDK 17+, and an NFC-capable device to test tap-to-pay. Want to deploy your own version of the payment contract? Check the README inside /contracts.
